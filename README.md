# Ethiopian Birr Notes Dataset

**Name:** Yohannes Gumata

**ID:** UGR/4852/15

This dataset contains 50 original photographs of Ethiopian Birr notes in five denominations. Each
denomination has ten photographs taken under different lighting and background conditions.

`FOREGROUND` contains the side marked "National Bank of Ethiopia". `BACKGROUND` contains the
reverse side of the note. `BACKGROUNDS` contains ten selected original background-side photographs.
The photographs are stored without cropping or image modification.
